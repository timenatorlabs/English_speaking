# Speak

毎日15分、英語を「口から出す」ためのトレーニングツール。無料で、インストールは不要です。

## 起動
1. `start.bat` をダブルクリックする
2. ブラウザで `http://localhost:8080` が開く(**Chrome か Edge** を使ってください)
3. マイクの使用を許可する

黒い画面のウィンドウを閉じると終了します。

### iPhone
公開した URL を **Safari** で開いてください。
- 音声認識が動かないときは、設定 → 一般 → キーボード →「音声入力」と、設定 →「Siri」をオンにしてください。
- お手本の音声とクリック音は、マナーモードでも鳴ります。ただし、自分で追加したカードの読み上げは鳴りません。
- iPhone では、スピーチ中の録音(自分の声を聞く機能)は使えません。録音を同時に行うと、音声認識が止まってしまうことがあるためです。
- 学習記録は、PC とスマホで別々に保存されます。移したいときは、「設定 → 書き出す / 読み込む」を使ってください。

## 毎日の流れ
| 手順 | 内容 | 操作 |
|---|---|---|
| 1 ドリル | 日本語を見たらすぐ英語で言う → お手本と比べる(読み上げ中の語に色が付く) → 必要なら繰り返して確認 → 自分で評価する → 最後に振り返り | `Space` 答え合わせ・繰り返す / `1` `2` `3` 評価 / `Enter` 提案された評価で決定 / `R` お手本 / `B` リズム |
| 2 スピーチ | 1つのお題について、同じ内容を 4分 → 3分 → 2分 の3回話す | `Space` 開始・終了 / `Enter` 次へ |
| 振り返り | 文字起こしを無料のAIで添削してもらい、言えなかった表現をカードとして追加する | 「添削プロンプトをコピー」→ AIに貼る → 返ってきた `日本語 \| English` の行を貼り付ける |

`Esc` でいつでも中断できます。それまでの評価は保存されます。

ドリルが終わると振り返りの画面が出ます。表示されるのは、「すぐ言えた」の数、平均反応時間(前回との比較)、言えなかった文の一覧です。お手本と違う言い方をした文は、まとめて無料AIに確認してもらえます。ホームの「記録」では、反応時間・「すぐ言えた」割合・WPM の推移と、苦手なカードを見られます。

### レベル
ホームで、中1・中2・中3・高1・高2・高3 の中からレベルを選べます。レベルは、その文を言うのに必要な文法を習う学年で分けています(中1 は be動詞・一般動詞・過去形、中3 は現在完了・関係代名詞、高2 は仮定法過去完了・助動詞+have done、など)。新しいカードは選んだレベルからだけ出ます。復習のカードは、レベルに関係なく、期限が来たものがすべて出ます。各ボタンの下の数字は「学習したカード数/そのレベルの枚数」です。

### お手本の速さ
答え合わせの画面の「速さ」ボタンで、1.0倍 → 0.85倍 → 0.7倍 と切り替わります(`S` キー)。声の高さは変わりません。

### リズム譜
ドリルの答え合わせでは、お手本の英文がドラム譜のような形で表示されます。強く読む音節はアクセント(>)付きの音符で拍の頭に置き、弱く読む音節はゴーストノート(かっこ付きの音符)にして、拍と拍の間に詰めています。「♩ リズム」ボタン(または `B`)を押すと、まず「お手本の番」になります。4カウントの後、強い音節がクリックに乗るように調整したお手本が流れます。続けて「あなたの番」になり、4カウントの後にクリックだけが鳴るので、同じように言ってください。クリックには強い音節を合わせ、弱い音節は短くあいまいに言います。テンポは文ごとに、自然に話す速さに近い値になっています。
英語の強勢が実際に等間隔で並んでいるわけではありません。この譜面は、強弱の差をはっきりさせるための練習用のものです。リズムの注釈は最初から入っているカードにだけ付いています。自分で追加したカードには表示されません。

## この方法を選んだ理由
- **すぐに思い出して言う練習と間隔反復**: 話せない原因の多くは、知っている表現をとっさに取り出せないことです。そこで反応時間を測り、詰まったカードほど早く復習に戻します。よく使う定型表現(チャンク)を使える人ほど流暢に話せることがわかっています(François & Albakry 2021 ほか)。
- **4/3/2**: 同じ話を、時間を縮めながら繰り返します。回を重ねるごとに発話速度が上がり、言いよどみが減ることが確認されています(Nation 1989、Thai & Boers 2016)。
- **自分専用のカード**: 言えなかった表現をドリルに戻すと、練習が自分の話したい内容に近づいていきます。

## お手本の音声
最初から入っている200枚のお手本は、音声ファイル(`audio/cards/`)として用意してあります。iPhone のマナーモードでも鳴るようにするためです。各単語の読み始めの時刻は `data/audio.js` に入っていて、単語の色付けと譜面上の縦線は、この時刻に合わせて動きます。自分で追加したカードは、ブラウザの読み上げ機能を使います(マナーモードでは鳴りません)。

カードの英文を変更・追加したときは、次のコマンドで音声を作り直します。English_listening の Piper と faster-whisper を使います。

```
C:\develop\English_listening\.venv\Scripts\python.exe -I tools\make_audio.py
```

## データについて
- 学習記録はブラウザの中(localStorage)だけに保存されます。「設定」からJSONファイルに書き出して、バックアップできます。
- 音声認識はブラウザの機能を使うため、話した音声は Google などのサーバーで文字に変換されます。
